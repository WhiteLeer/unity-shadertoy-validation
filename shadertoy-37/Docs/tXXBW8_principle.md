# tXXBW8 (CILIA) 原理解析

## 1. 效果类型
- 单 `Image` pass，纯程序化。
- 视觉上是大量纤毛/丝状结构围成的圆柱形体积。

## 2. 主体流程
1. 用极坐标角度把圆周切成很多细小纤毛段。
2. `TraceCilia()` 沿视线逐层扫描，找到离相机最近的一层纤毛截面。
3. `RadiusAt()` 给每一层加入时间扰动和随机半径变化，让边缘不规则摆动。
4. `Fbm()` 在命中位置叠加体积噪声，形成内部的明暗层次。
5. 最后做指数压亮、gamma 和暗角。

## 3. 关键直觉
- 不是传统表面 raymarch，而是“分层扫描很多薄片”，每片上判断是否落在纤毛外侧。
- `fiber` 参数记录局部截面形状，最后直接控制亮度和厚薄感。
- `Fbm()` 负责内部云雾感，`RadiusAt()` 负责外轮廓的毛刷感。

## 4. Unity 对应
- `iResolution -> _STResolution.xy`
- `iTime -> _STTime`
- `iFrame -> _STFrame`
