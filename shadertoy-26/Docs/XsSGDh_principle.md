# XsSGDh (marble) 原理解析

## 1. 效果类型
- 单 `Image` pass。
- 一个玻璃/大理石质感球体，内部带有吸收、扭曲和环境反射。

## 2. 主体流程
1. `Trace()` 先和球壳求交，再在球体内外切换折射/反射。
2. `Warp()` 扭曲内部坐标，制造大理石纹路的流动感。
3. 内部颜色由纹理、体积吸收和玻璃底色共同累积。
4. 外部再叠加环境反射、背景条纹、噪点和对比度曲线。

## 3. 关键直觉
- 这不是简单表面材质，而是“多次穿过玻璃体”的近似体积渲染。
- 反射高光来自环境方向采样。
- 内部花纹来自扭曲采样和指数衰减，不是普通贴图直接贴在表面。

## 4. Unity 对应
- `iResolution -> _STResolution.xy`
- `iTime -> _STTime`
- `iMouse -> _STMouse`
- `iChannel1 -> _Channel1`
- `iChannel2/3` 作为环境图以 2D 经纬采样近似 cubemap
