# dtXGzH (Volumetric Fur Balls) 原理解析

## 1. 效果类型
- 单 `Image` pass。
- 用短步进体积累加做出毛球/绒球的半透明体积感。

## 2. 主体流程
1. 先把屏幕分块并构造每个像素的步进方向 `d`。
2. 从观察点 `o` 出发，沿 `d` 做 32 次固定步长采样。
3. `Density()` 把球体距离、贴图噪声和时间波动合成一个体积密度。
4. 每一步用当前密度与前后差值累计颜色，形成类似毛发层层叠加的效果。
5. 最后做一次 `sqrt(c/(1+c))` 压亮，得到柔和发光感。

## 3. 关键直觉
- 这不是标准表面着色，而是“在体积里不断积累颜色”。
- 贴图只负责打散边缘和内部噪声，让球体看起来像毛茸茸的。
- 颜色按屏幕横向区域切换，所以左右会有不同色调的毛球。

## 4. Unity 对应
- `iResolution -> _STResolution.xy`
- `iTime -> _STTime`
- `iChannel0 -> _Channel0`
