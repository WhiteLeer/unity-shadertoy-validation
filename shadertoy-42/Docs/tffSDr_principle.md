# tffSDr (iridescent fibers) 原理解析

## 1. 效果类型
- 单 `Image` pass，纯程序化。
- 目标是多层彩虹纤维/丝线叠加的流动效果。

## 2. 主体流程
1. 把像素坐标归一化到以屏幕中心为原点的空间。
2. 用 `palette()` 生成随时间和横向位置变化的彩虹色。
3. 叠加 10 层正弦波，每层的振幅、相位、厚度略有不同。
4. 每层通过 `smoothstep` 形成柔和的发光线条，最后累加成整体纹理。

## 3. 关键直觉
- 不是在画“面”，而是在重复画很多条有厚度的亮线。
- `phase` 控制流动，`amp` 控制摆动，`thick` 控制边缘柔和度。
- 彩虹感来自余弦调色板，而不是贴图采样。

## 4. Unity 对应
- `iResolution -> _STResolution.xy`
- `iTime -> _STTime`

## 5. 输入通道
- 无外部输入（纯程序化）
