# ftlyRS (Kaleidoscope Crystal) 原理解析

## 1. 效果类型
- 这是一个纯程序化晶体/万花筒效果。
- 没有贴图输入，也没有 buffer pass。
- 主体由 SDF 距离场、空间折叠、折射/反射迭代和发光累积组成。

## 2. 空间结构
- `lattice` 反复旋转坐标，并对 `yz` 做 `abs(p.yz)-1` 的折叠。
- 这种折叠会把一个简单盒子距离场复制成万花筒式晶格。
- `bx` 是 box SDF，决定晶体薄片/边界的基础形状。
- `abs(sd)-0.001` 把实体边界变成极薄壳层，让折射时更像透明晶体表面。

## 3. 光线流程
- 从相机位置 `ro` 发出视线 `rd`。
- `tr` 做 sphere tracing，沿射线寻找晶体壳层。
- 命中后通过邻近 SDF 差分计算法线。
- 根据当前进出状态交替使用 `refract(rd, n, 1/io)` 和 `refract(rd, n, io)`。
- 如果发生全反射，就改用 `reflect`。
- 最多迭代 25 次，把每次穿透/反射看到的颜色按 alpha 累积。

## 4. 视觉来源
- 背景色来自视线方向和累积 glow。
- 表面颜色来自法线、折射方向、简单高光、AO 近似和壳层 glow。
- `gl += exp(-sd*0.001) * normalize(p*p) * 0.003` 是沿途发光积累，让晶格内部有朦胧亮度。
- `fc += vec4(cc*oa, oa)*(1-fc.a)` 是前向 alpha 合成，模拟多层透明晶体。

## 5. Unity 迁移注意
- 原 GLSL 使用全局可变变量，Unity 版改成 `CrystalState` 结构体，避免 HLSL 全局状态在编译器里产生不确定行为。
- `mat2` 旋转被替换为显式 `Rot2`，避免 GLSL/HLSL 矩阵构造和乘法顺序问题。
- 原始 `nm` 使用 `mat3(cp,cp,cp)-mat3(.001)` 构造三个偏移点，Unity 版直接写成 `cp - axisEpsilon`，语义更明确。
- 输出时对 alpha 做 `max(fc.a, 1e-4)`，避免空采样导致除零。

## 6. 可调方向
- 晶格复杂度：`Lattice(p, 9, ...)` 中的迭代次数。
- 旋转速度：`tt * 0.1` 相关项。
- 透明层数：render 循环中的 25 次上限。
- 折射率：`io = 1.2`。
- 壳层厚度：`abs(sd)-0.001` 的阈值。
